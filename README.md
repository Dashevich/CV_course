## Описание экспериментов

### 1. Подготовка данных
- Использован датасет: Grapevine Leaves Image Dataset (5 классов)
- Разделение: 70% train, 15% validation, 15% test(не использовался)
- Аугментации: RandomResizedCrop, RandomHorizontalFlip, нормализация
- Размер изображений: 224x224 пикселя

### 2. Архитектуры моделей
**Простая CNN:**
- 3 сверточных слоя (16, 32, 64 фильтров)
- MaxPooling после каждого слоя
- Полносвязный классификатор с двумя линейными слоями

**ViT-Tiny:**
- Предобученная модель vit_tiny_patch16_224
- Замороженные веса backbone
- Обучаемый линейный классификатор на голове модели

### 3. Результаты экспериментов

**CNN:**
- Лучшая accuracy на валидации: 51.25%
- Обучение: 50 эпох
- Оптимизатор: Adam (lr=0.001)
- Планировщик: StepLR (шаг 10 эпох, gamma=0.1)

**ViT-Tiny (linear probe):**
- Лучшая accuracy на валидации: 73.75%
- Обучение: 30 эпох
- Оптимизатор: Adam (lr=0.001) только для головы
- Планировщик: StepLR (шаг 10 эпох, gamma=0.1)

### 4. Наблюдения
- ViT-Tiny значительно превосходит простую CNN (73.75% vs 51.25%)
- Предобученные трансформеры показывают excellent performance даже без тонкой настройки
- CNN медленнее сходится и показывает меньшую точность
- Обе модели выигрывают от использования планировщика learning rate

### 5. Визуализация
- Логи обучения в TensorBoard включают:
  - Loss и accuracy на train/validation
  - Confusion matrix
  - Гистограммы весов и градиентов
  - Learning rate
